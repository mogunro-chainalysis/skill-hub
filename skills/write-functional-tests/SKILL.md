# Write Functional Tests

Use when needing to design, implement, or audit functional tests for behavior-driven development.

## Procedure

1. **Identify Scenarios**: Define user-visible behaviors to test.
2. **Draft Steps**: Use Given/When/Then style for clarity.
3. **Implement**: Map steps to code using the project's testing framework.
4. **Verify**: Ensure tests fail on bad behavior and pass on good behavior.
