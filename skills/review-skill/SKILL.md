# Review Skill

Audit a skill, agent, or instruction file against quality principles and the standard.

## Procedure

1. **Read Principles**: Review `references/reference.md` for audit standards.
2. **Apply Checklist**: Check for blockers, suggestions, and repo-agnosticism.
3. **Scrub Check**: Verify no persona, company, or internal leaks exist.
4. **Output findings**: Report as Blocker (fix now) or Suggestion (improve later).
